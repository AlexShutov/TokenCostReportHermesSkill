## 20.10.2026 — баг: повторная установка перезаписывала состояние плана

Мажорный (меняет результат на живой машине):
- **setup.sh писал файл состояния безусловно** — при повторном запуске терялся сохранённый день
  якоря и план: файл создавался заново со значением «вчера». Теперь существующее состояние не
  трогается, день меняется только явным сеттером. Проверка чистой установки: второй запуск
  сохраняет уже записанный день.
