## 20.10.2026 — правило: в доставляемом сообщении нет размышлений

Критичный (без этого навык не работает без LLM):
- **Сообщение содержало оговорки** — окно, месячный лимит, модель пика, точечную атрибуцию,
  unknown-строки и MCP-оговорку. По правилу пользователя из всего вывода нужны ровно две
  строки: процент плана и строка про эквивалентный кодовый план. Теперь сообщение — эти две
  строки; оговорки пишутся в лог (stderr) и остаются в базе, откуда восстанавливаются запросом.
  Версия про токены включается только при переполнении Max — как частный случай, а не по
  общему количеству токенов. Переход плана больше не печатается в сообщение: состояние
  обновляется один раз, сообщение остаётся двухстрочным.

Тесты: 39 + 91 + 29 + 8 = 167.
