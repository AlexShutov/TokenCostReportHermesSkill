## 20.10.2026 — плагин-команда /token-cost-daily (запуск сразу, без хода агента)

- `plugin/` — обработчик плагин-команды: вызывает тот же скрипт, что и крон-задача, и
  возвращает None, потому что сообщение уже отправляет скрипт одним сообщением через Bot API
  (прежнее трэкированное сообщение удаляется). Если бы обработчик возвращал текст, гейтвей
  добавил бы в чат вторую копию — нарушение правила «ровно одно сообщение на навык».
- Чат берётся из сессионного контекста гейтвея, а не hardcoded: команда работает в том чате,
  где её набрали; вне гейтвея — переменная, иначе значение по умолчанию.
- Плагины opt-in: без `plugins.enabled` обработчик не загружается; `setup.sh` копирует файлы
  и печатает команду включения, существующие файлы не перезаписывает молча.
- Тесты `tests/test_plugin_command.py` — 8 проверок, offline, mock-spawn: None-возврат, чат из
  сессионного контекста, цепочка фолбэков, ошибка запуска сообщается строкой, путь не тянет
  модель. Проверка конфликта имён пропускается, если исходники Hermes не импортируются.

Тесты: 45 + 91 + 29 + 17 + 8 = 190; чистая установка 39 проверок.
